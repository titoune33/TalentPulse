# TalentPulse

> SaaS platform for talent management and analytics

## Structure

```
TalentPulse/
├── frontend/
│   ├── app/
│   │   ├── (pages)/
│   ├── components/
│   ├── lib/
│   └── prisma/
└── backend/
    ├── models/
    └── services/
```

## Setup

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```
